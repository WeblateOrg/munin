Munin monitoring for Weblate
============================

.. image:: https://s.weblate.org/cdn/Logo-Darktext-borders.png
   :target: https://weblate.org/
   :alt: Weblate
   :height: 55px

Maintained by `Weblate <https://weblate.org/>`_ — a privacy-respecting localization platform built on open-source foundations.

Installation
------------

1. Copy ``weblate`` to /etc/munin/plugins/
2. Copy and edit ``weblate_servers`` to /etc/munin/plugin-conf.d/
